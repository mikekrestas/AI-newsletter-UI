Your Gmail, your reading room.

Signal is a personal newsletter reader. It uses free Gmail API access and browser storage. There is no paid API, database or required paid subscription. For hosted daily reports that work on your phone, follow the daily summary setup guide. To stay connected after refreshing or closing the browser, follow the persistent sign-in setup guide.

1. Label your newsletters

In Gmail, create a label called AI Newsletters. Add representative editions from TLDR, AlphaSignal and DAIR.AI. Set up sender-based filters to apply it automatically, checking the actual senders in your emails. You can also choose “Skip the Inbox” in Gmail if you want newsletters out of your main inbox.

2. Create your free Google connection

  1. Open Google Cloud Console and create a project. This app does not need a billing account, an API key or any paid Google services.
  2. In APIs & Services → Library, enable the Gmail API.
  3. Open Google Auth Platform. Under Branding, enter an app name and your email as the support/developer contact. Under Audience, choose External and leave the app in Testing. Add your own Gmail address as a test user.
  4. Under Data Access, add https://www.googleapis.com/auth/gmail.readonly. This allows reading mail; the app does not request permission to send or modify it.
  5. Under Clients, create an OAuth client with application type Web application. Add the app’s exact origin to Authorised JavaScript origins. For local use, add http://localhost:3000. For a hosted copy, use its HTTPS origin, without a path or trailing slash. Signal shows your current origin in Settings. No redirect URI is needed for this popup token flow.
  6. Copy the client ID, open Signal’s Settings, paste it and save. The client ID is public configuration. Do not paste the client secret.
  7. Click Connect Gmail, select your account and grant read-only access. If Google shows an unverified-app warning, proceed only for the app you created yourself. Your personal testing app is not publicly verified.

3. Read at your own pace

Catch up contains the last seven days of editions you have not read or dismissed in Signal. Saved keeps your selected editions. Archive includes all loaded editions. Load older editions when you want to explore more.

Reading in Signal does not mark messages read in Gmail. Saved/read/dismissed states stay in the current browser and are separated by Gmail account. Clearing site data removes that progress. Newsletter bodies are fetched when needed. Completed daily briefs and their source metadata are stored privately for 30 days, so you can read them on another device.

The temporary popup connection holds its access token in browser memory and needs reconnection after a reload. With persistent sign-in activated, a secure HttpOnly cookie restores your account and the server refreshes Gmail access automatically. Google’s read-only scope covers the mailbox; the app limits its requests to your chosen label and editions you explicitly saved. Email images, scripts and forms are removed from the reader. Temporary access tokens are not stored by the backend. Persistent sign-in encrypts access and refresh tokens in your private Cloudflare KV, using a Worker secret; browser JavaScript never receives them. Generating a brief sends selected newsletter text to Cloudflare Workers AI.

Free hosting for phone use

Use the full project and run npm install then npm run setup:hosted on your PC. Sign in to your free Cloudflare account and paste your public Google OAuth client ID when asked. This publishes the website and its AI backend together. Add the resulting https://…workers.dev origin to your Google OAuth client, then open that website on your phone. Uploading only the public folder will not include the AI backend.

Troubleshooting

  • Origin mismatch: make sure Google lists exactly the origin displayed in Settings, including the port for localhost. Configuration changes can take time to propagate.
  • Access blocked: add your Gmail address as a test user and enable the Gmail API in the same project as your client ID.
  • No newsletters: verify the label exists and contains messages. LinkedIn notification emails may only contain a teaser; use their original links for the full edition.
  • Google popup does not open: allow popups for the app and click Connect Gmail again once Google sign-in has loaded.
  • Saved edition missing: if its original message was deleted from Gmail, this app cannot recover it. Archived messages remain accessible.
